# 城市出行客流数据分析系统 UI 设计规范

## 设计定位

面向本科毕业答辩与日常数据分析的轻量城市交通控制台。视觉关键词为“科技蓝、清晰、克制、可信”，使用浅色内容区与深蓝导航形成稳定层级，不采用霓虹大屏、在线字体或装饰性重动画。

## 色彩 Token

- 品牌主色：`#1769E0`，用于主要操作、选中态和关键趋势。
- 品牌深色：`#0B1F3A`，用于侧栏和高权重文字。
- 辅助青色：`#0EA5A8`，用于实时状态和辅助数据系列。
- 页面背景：`#F3F6FA`；卡片背景：`#FFFFFF`。
- 主文字：`#142033`；次文字：`#5E6B7C`；弱文字：`#8B98A9`。
- 边框：`#E2E8F0`；悬浮填充：`#EDF4FF`。
- 成功：`#16A36A`；警告：`#E49A16`；危险：`#DC4C64`；信息：`#4C7EF3`。

状态必须同时显示图标或文字，不能只依赖颜色。

## 字体与数字

系统字体栈：`Inter, "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`，不请求在线字体。

- 页面标题：24px / 700。
- 区块标题：16px / 650。
- 卡片数字：28px / 700，使用等宽数字特性。
- 正文：14px / 400，行高 1.6。
- 说明文字：12px / 400。

## 间距、圆角与阴影

- 间距：4、8、12、16、24、32、48px。
- 输入与按钮圆角：8px；卡片圆角：12px；状态胶囊：999px。
- 卡片阴影：`0 8px 24px rgba(31, 45, 61, 0.06)`，不使用厚重发光。
- 内容最大化利用屏幕，但卡片之间至少保留 16px 呼吸空间。

## 布局

- 左侧导航：240px，1366px 以下收窄为 76px。
- 顶栏：64px，显示页面标题、运行模式、系统健康和当前用户。
- 主内容：24px 外边距，1366px 下调整为 16px。
- 1920×1080 下首页核心内容尽量一屏展示；1366×768 下允许主内容自然纵向滚动，禁止横向滚动。

## 组件规范

- 指标卡：图标、标签、主数值、趋势/说明四层信息；数值必须来自 API。
- 图表卡：标题、业务说明、时间/筛选控件、图表、空/错/加载状态完整。
- 表格：表头固定、行高舒适、操作区紧凑；危险操作二次确认。
- 表单：标签清晰、错误就地显示；长任务按钮进入 loading 并提供任务状态。
- 弹窗：用于确认和短表单，不承载复杂整页内容。

## 图表规范

- 主折线采用 `#1769E0`，预测线采用 `#0EA5A8`，风险系列采用状态色。
- 坐标轴、单位、时间范围、图例必须清楚。
- 折线图使用低透明度面积；柱状图使用适度圆角；饼图不超过 6 类。
- 图表容器必须监听 ResizeObserver，避免侧栏切换后尺寸错误。
- 地图只加载本地 GeoJSON，提供区域热力、站点散点和 OD 流向三层。

## 动效与可访问性

- 过渡时长 160–220ms，仅用于悬浮、展开和状态变化。
- 遵循 `prefers-reduced-motion`。
- 正文与背景对比度至少满足 WCAG AA；键盘焦点轮廓清晰。
- 空状态说明下一步操作；错误状态提供可理解的原因和重试入口。
