## 已完成功能

- Vue 3 + Vite + Element Plus + ECharts 管理端，包含登录、总览、数据、离线分析、实时客流、预测、预警、报告、用户、日志和设置页面。
- FastAPI + SQLite 模块化后端，包含身份认证、RBAC、操作审计、运行健康和全量业务 API。
- 固定“星海示例市”基础目录：8 个区域、40 个站点、12 条线路；所有数据层共享区域、站点、线路、坐标与容量。
- 本地 `assets/maps/demo_city.json` GeoJSON，以及区域热力、站点分布、Top-N OD 流向和实时客流四类地图模式。
- 固定 CSV、JSON、XLSX 演示数据；Spark 清洗、校验、Parquet 分区、Spark SQL 指标与 OD 分析。
- Spark Structured Streaming 实时模拟，包含启动、暂停、继续、停止、重置、窗口指标、查询健康和实时预警。
- ARIMA、Spark RandomForestRegressor、Spark GBTRegressor 三类真实模型，包含时间顺序拆分、MAE、RMSE、R²、未来预测和模型比较。
- 基于站点容量的负载率、分级预警、地图状态同步、决策建议和报告导出。
- 项目内置 Python 3.11、JRE 17、PySpark 3.5.6 与 Windows Hadoop 本地文件支持，不要求目标机预装开发环境。
- `启动系统.exe` / `关闭系统.exe`、端口探测、后端与 Spark 就绪检查、浏览器打开、进程树关闭和相对路径运行。

## 数据声明

当前系统使用内置模拟城市交通数据集进行功能验证，通过本地 GeoJSON、虚拟站点及线路数据完成客流分析、OD 流向、预测与预警。实际应用时可通过替换城市 GeoJSON、站点、线路和真实客流数据迁移到实际城市环境。
